# DGN M0: WFC Generator 1.3.3: shared solver

Prepare the WFC Generator patch release for the move and the shared menu and preview: CHANGELOG entry, `plugin.cfg` version, and the README note that WFC Generator and Dungeon Generator are updated together. The board tags `wfc_generator-v1.3.3` at the M0 review.

Brief: §4.1, §8 (WFC unchanged).

## Done when
- A test opens a scene saved with 1.3.2 and generates the same cells for the same seed.
- A test loads a path-only tile set (old script path) through the legacy stub and solves with it.
- `tools/package_addon.sh wfc_generator 1.3.3` builds a zip that passes `tools/smoke_test_addon.sh`.

## Notes from `dgn-m0-shared-solver-move`
- **Packaging:** `tools/package_addon.sh` copies all of `editor_tools_common`, so a MultiMesh Scatter zip would now ship the WFC resource classes too (three extra global classes in Create Resource, and the duplicate-uid case of brief §10.2 next to an old WFC Generator). Leave `editor_tools_common/Wfc` out of zips for addons that do not use `Godoodads.Common.Wfc`. Check `git archive` with a `:(exclude)` pathspec.
- **README:** in Updating, say to replace `editor_tools_common` together with `wfc_generator`, and to open the project in the editor once so saved files find the moved scripts. Under "If something goes wrong", explain the "UID duplicate detected" warning (an old copy left behind).
