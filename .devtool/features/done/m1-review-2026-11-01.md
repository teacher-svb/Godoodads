# M1: Milestone review

Demo: the legacy-style result on the demo terrain, test run, undo and append checks.

## Review checklist for the board

Open `demo/multimesh_scatter/demo.tscn`, select `Scatter`, then **MultiMesh &gt; Scatter Surface…**, pick `Terrain`:

1. **Populate** with defaults. 128 instances on the terrain; status shows `Placed 128 / 128 … Seed 0`.
2. **Seed:** press Populate twice with the same seed and get an identical result. **Randomise Seed** gives a different one.
3. **Spacing:** set Min Distance to 1 and Amount to 300. The instances are evenly spread. Set Min Distance to 3; the status reports a shortfall "by spacing".
4. **Undo:** Ctrl+Z restores the previous instances; redo reapplies them.
5. **Append:** set Output Mode to Append, pick `Sphere`, Populate. The terrain instances remain and the sphere gets new ones (with Min Distance &gt; 0 they keep their distance).
6. **Persistence:** save, close and reopen the scene, then reopen the dialog. The last settings and surface are restored.
7. **CSG:** pick `CsgShape` (root) to populate; pick its child `Box` to see the error.
8. **Legacy comparison:** with Tilt 0 the result is visually equivalent to the old plugin (upward-facing filtering arrives with the M2 slope filter).
