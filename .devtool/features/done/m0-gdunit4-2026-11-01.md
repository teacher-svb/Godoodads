# M0: GdUnit4 for engine-dependent tests

Install GdUnit4 (C#) for tests that need the engine (Image, Mesh, MultiMesh, EditorPlugin bits).

**Files**
- NuGet references: `gdUnit4.api`, `gdUnit4.test.adapter`
- `.runsettings` that points `GODOT_BIN` at Godot 4.7 .NET
- One sample engine test under `tests/multimesh_scatter/`

**Acceptance**
- `dotnet test --settings .runsettings` runs the engine test headless and passes.

## Result
- Uses `gdUnit4.api` 5.1.0-rc5 with `gdUnit4.test.adapter` 3.1.1, released together. Adapter 3.2.0 needs a newer api and fails with `Method not found: set_GodotConnectTimeout`.
- Command: `dotnet test Godoodads.csproj --settings .runsettings`
- Headless findings: mesh surface arrays and `Image` work, and `MultiMesh.Buffer` round-trips. `MultiMesh.GetInstanceTransform` returns zeros, so do not assert on it.
