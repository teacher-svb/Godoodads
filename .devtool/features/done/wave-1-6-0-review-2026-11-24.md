# godoowave 1.6.0: Release review

Ships card `wfc-1-6-socket-lists-2026-11-24`: several comma-separated socket labels on one face (brief §17). The 2D adapter cards moved to 1.7.0 on 2026-11-24 (board decision).

## Done when
- `addons/godoowave/plugin.cfg` is 1.6.0, and the root README names `godoowave-1.6.0.zip` and plans 2D for 1.7.
- The godoowave CHANGELOG has a 1.6.0 entry that says single-label tile sets give the same cells.

## Review checklist for the board
1. Build, focus Godot so it reloads the C# assembly, then toggle **godoowave** in *Project Settings → Plugins*.
2. On a `WfcTile`, clear a socket field: it shows *label, or labels separated by commas*.
3. Set a face to `wall, window` on one tile and `window` on the facing side of another: the preview lists the other tile as a neighbour and the face is not red. `wall,,window` gives an error on that face.
4. In the preview, click a face label: the popup shows the placeholder and the hint. Type `wall, ` and pick a suggestion: the face becomes `wall, <suggestion>`.
5. Generate the hillside demo: same result as 1.5.1 for the same seed.
