# CRV M4: Demo scenes

`demo/godoocurves/tools/build_demo.tscn` (replacing the M2 review builder) builds three scenes with the addon's own code, each path with its `CurveSettings` stored, so the dialog can continue from them:

- **shapes.tscn:** every shape at its defaults on its own path, labelled, with a channel profile that shows up and tilt.
- **coaster.tscn:** a ride appended piece by piece (straight, banked turns, loop with Side Shift, wave, corkscrew, helix, S-bend, back to the start area), a deck-and-rails profile (`CSGPolygon3D`, path follow), pillars to the ground, a train on a `PathFollow3D` (rotation mode XYZ, tilt enabled) with an onboard camera, and an overview camera.
- **outlines.tscn:** closed shapes in use: a fence on a Rounded Rectangle, a flower-bed border on a Polygon, a pond rim on an Ellipse, and a running track on a Figure Eight.

## Result
`demo/godoocurves/tools/build_demo.tscn` (`BuildCurvesDemo.cs`) builds three scenes with the addon's own code. It replaces the M2 review builder and scene. Every path stores its `CurveSettings`.
- **shapes.tscn:** all 16 shapes at the defaults, labelled, each with a U channel open toward its up.
- **coaster.tscn:** a 365 m ride, 66 points, 5 to 22.4 m high, built with `CurveWriter.Append` from 15 pieces in this order:
  - station straight
  - lift and drop: vertical arcs and straights, smooth, with no Helix kink
  - banked turn left (40°)
  - loop with Side Shift 3
  - wave
  - corkscrew
  - banked turn right
  - S-bend and a straight

  It has a deck-and-rails profile and 49 steel pillars wherever the track runs upright above the ground. Three cars on `PathFollow3D` (rotation mode XYZ, tilt enabled) ride a 45-second lap; the first carries the current camera, so running the scene (F6) rides the train. The overview camera is for the editor.
- **outlines.tscn:**
  - a white fence on a 40 × 28 Rounded Rectangle (corner radius 5)
  - a brick flower-bed border on a hexagon
  - a stone pond rim on an Ellipse with a water disc
  - a clay running track on a Figure Eight
- Closed outlines use `CSGPolygon3D.path_joined`.
- All three scenes build headless and load without errors, and 127 engine tests pass. The build command is in CLAUDE.md.
