# WFC 1.1: Release review

Demo for the board. The board moves this card to *Done* when approved, after which the release is tagged `wfc_generator-v1.1.0`.

## Review checklist for the board
1. Open the rebuilt demo and generate with several seeds. Judge the look against 1.0.
2. Generate twice in a row without undoing. Edit a generated cell by hand, generate again, and check it was kept.
3. Set a tile's weight to 0 and check it is never generated, but can still be placed by hand.
4. Read the acceptance results and the CHANGELOG note about changed results.
