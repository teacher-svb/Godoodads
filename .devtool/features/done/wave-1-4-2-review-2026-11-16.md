# godoowave 1.4.2: Release review

Ships two fixes to the shared WFC code in `addons/editor_tools_common/Wfc/` to godoowave users. They are made on the godoodungeon 1.0.1 branch: cards `dgn-1-0-1-one-layer-height-curves-2026-11-16` and `dgn-1-0-1-preview-external-sockets-2026-11-16`. godoowave gets them through its own zip, which includes `editor_tools_common`.

- One-layer grids (Bounds Size Y = 1, and Measure with Sample Y = 1) now apply height curves, as taller grids already did.
- The tile set preview updates when External Sockets change.

## Done when
- `addons/godoowave/plugin.cfg` is 1.4.2, and the root README names `godoowave-1.4.2.zip`.
- The godoowave CHANGELOG has a 1.4.2 entry for both fixes. It says that results change for one-layer bounds whose tile set uses height curves, and only there; tile sets without curves give the same cells.
- Released after godoodungeon 1.0.1, from the same main commit or later.

## Status
Version 1.4.2 in `plugin.cfg` and the root README and the CHANGELOG 1.4.2 entry are on the godoodungeon 1.0.1 branch (`godoodungeon-1-0-1-review-fixes`), so both release from the same main commit.

## Review checklist for the board
1. Focus Godot so it reloads the C# assembly, then toggle **godoowave** in *Project Settings → Plugins*.
2. On a tile set where one tile has a height curve of 0 at the bottom, set Bounds Size Y = 1 and Generate: that tile does not appear.
3. Add an External Socket to a tile set with the preview open: the matching red labels turn white without reselecting the tile set.
4. Read the CHANGELOG 1.4.2 entry.

The board moves this card to *Done* when approved, after which the release is tagged `godoowave-v1.4.2`.
