# godoodungeon 1.3.0: Release review

Ships the comma-separated socket lists of the shared WFC solver (card `wfc-1-6-socket-lists-2026-11-24`, godoowave 1.6.0) to godoodungeon users. Brief §14. The code is already on main (PR #33); this release adds the version, CHANGELOG, README and brief.

## Done when
- `addons/godoodungeon/plugin.cfg` is 1.3.0, and the root README names `godoodungeon-1.3.0.zip`.
- The CHANGELOG 1.3.0 entry says single-label tile sets give the same dungeon, and that godoowave next to it must be 1.6.0 or later.
- The PR is merged and the tag `godoodungeon-v1.3.0` is pushed on the merge commit; the *Release addon* workflow passes and publishes the release.

## Review checklist for the board
1. Build, focus Godot so it reloads the C# assembly, then toggle **godoodungeon**.
2. In the demo room tile set, give a wall's inner face a list such as `in, window` and check the tile rules stay clean and Generate still works.
3. Give a wall a face `outside+, x`: the rules accept it as a room edge.
4. Generate the demo dungeon: same result as 1.2.1 for the same seed.
