# WFC 1.3: Release review

Demo for the board. The board moves this card to *Done* when approved, after which the release is tagged `wfc_generator-v1.3.0`.

## Review checklist for the board
1. Edit a socket in the preview, undo it, and find a red unmatched label.
2. Measure the demo tile set and compare weight and measured shares.
3. Open `hillside_paths`, generate with several seeds and wander values, and pin part of a path.
4. Read the acceptance results.
