# godoodungeon 1.2: Room boxes: dialog, handles, preview and status

Room Boxes group with **Add Room Box** (one undo step). With the GridMap selected and the dialog open, bounds and every enabled room box with handles (`IBoundsBoxes`); a drag is an undo step on the node. Preview Layout draws boxes per mode with their numbers and Built doors. Status counts boxes; errors name the box and draw it in red.

Brief: §13.1, §13.5.

## Done when
- Engine tests: Add Room Box placement and undo; error messages of §13.2 name the node.
- Manual: drag boxes with the GridMap selected, Generate, regenerate with other seeds, Clear Dungeon, Preview Layout labels.

## Results (2026-11-20)
- `DungeonSettings`: **Room Boxes** group with **Add Room Box** (`AddRoomBoxRequested`). The plugin adds a Generated `DungeonRoomBox` named RoomBox (RoomBox2, …) owned by the edited scene at `DungeonRoomBox.CentredIn` (centred, Max Room Size on X/Z within the bounds, Room Height), one undo step, selects it and says which room it is.
- Handles: handle ids are now box × 6 + face (as `BoundsGizmoPlugin` draws them); box 0 is the bounds, boxes 1–n the enabled room box children. A drag moves the node captured at press and commits one undo step on its Origin and Size ("Resize Room Box"); cancel restores. The overlay state includes the boxes, so handles follow undo.
- Preview Layout: box rooms in their own colour (Generated light cyan, Built orange) with their height; numbers as in 1.1; Built doors drawn as doors. The preview key includes every box (name, origin, size, mode) and the Door item.
- Status: "Generated 12 rooms (2 room boxes, 1 built), …" and the same in the preview line. Errors that name a box draw it in red (from Generate and from the preview).
- Box checks now run once before the layout attempts (job and preview): an invalid box gives an Invalid result with each error once, not one failed attempt per layout.
- Tests: `CentredIn`; Add Room Box do/undo on a plain `UndoRedo`, saved with the scene; a job with two invalid boxes is Invalid with two errors naming them and no attempts. Engine 152/152, Core 519/519, editor load clean.
