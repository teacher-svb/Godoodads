# godoowave 1.5: Release review

Demo for the board. The board moves this card to *Done* when approved, after which the release is tagged `godoowave-v1.5.0`.

## Review checklist for the board
1. Open the hillside demo: Generate, and check the ruin stays and the clearing stays empty.
2. Add a pin box with Add Pin Box, drag its handles with the GridMap selected, Generate.
3. Select a pin box with the dialog closed and drag its handles; move it with the move tool.
4. Clear Bounds with Keep Placed Cells on and off: pin box cells stay.
5. Disable a pin box and regenerate: its cells are replaced.
6. Read the acceptance results.
