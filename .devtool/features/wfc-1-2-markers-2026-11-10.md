# WFC 1.2: Marker tiles

Optional `Marker` PackedScene on `WfcTile`. After a successful solve, instance it at each generated cell with the cell transform, under a `WfcMarkers` child of the GridMap owned by the edited scene, tagged with metadata. Generate removes the tagged markers inside the bounds first. All in the same undo action.

Brief: §12.4.

## Done when
- Engine tests: markers are placed with the right transform for each rotation, empty tiles can carry markers, regenerate removes only tagged markers inside the bounds, undo and redo restore them, hand-placed cells get no markers.
- Markers are saved with the scene and survive reopening it (manual check).
