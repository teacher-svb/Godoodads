# CRV M4: Demo scenes

`demo/godoocurves/tools/build_demo.tscn` (replacing the M2 review builder) builds three scenes with the addon's own code, each path with its `CurveSettings` stored, so the dialog can continue from them:

- **shapes.tscn:** every shape at its defaults on its own path, labelled, with a channel profile that shows up and tilt.
- **coaster.tscn:** a ride appended piece by piece (straight, banked turns, loop with Side Shift, wave, corkscrew, helix, S-bend, back to the start area), a deck-and-rails profile (`CSGPolygon3D`, path follow), pillars to the ground, a train on a `PathFollow3D` (rotation mode XYZ, tilt enabled) with an onboard camera, and an overview camera.
- **outlines.tscn:** closed shapes in use: a fence on a Rounded Rectangle, a flower-bed border on a Polygon, a pond rim on an Ellipse, and a running track on a Figure Eight.

## Done when
- Scenes build headless, open without errors and run (F6) with the train riding the coaster.
- Board check on result quality at the M4 review.
