# godoodungeon 1.2: Release review

Demo for the board. The board moves this card to *Done* when approved, after which the release is tagged `godoodungeon-v1.2.0`.

## Review checklist for the board
1. Open the room box demo: Generate with a few seeds; the boss room stays as built and both boxes are connected.
2. Add a room box with Add Room Box, switch it between Generated and Built, drag its handles, Generate.
3. Select a room box with the dialog closed and drag its handles.
4. Clear Dungeon: Built cells stay, Generated box cells go.
5. Check the graph: the boss room has its `Box` and Data after regenerating.
6. Read the acceptance results.
